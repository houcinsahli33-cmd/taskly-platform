# Taskly

Plateforme clients/artisans avec demandes réelles, avis, vérification professionnelle et administration.

- Fichiers publics : `client/public/`.
- Pages protégées : `client/private/`.
- Serveur Express : `server/`.
- Installer les dépendances avec `npm ci`, configurer les variables privées de `server/.env`, puis lancer `npm start`.
- Vérifier le code avec `npm run check` et `npm test`.

Voir [DEPLOIEMENT.md](DEPLOIEMENT.md) pour la configuration et les migrations, [README_SECURITE.md](README_SECURITE.md) pour les protections et [COMPTES_ET_SUPPORT.md](COMPTES_ET_SUPPORT.md) pour les comptes et le support.
